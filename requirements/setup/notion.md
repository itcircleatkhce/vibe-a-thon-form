# Notion Setup

Notion is an all-in-one workspace that combines note-taking, project management, databases, and collaboration. It's perfect for organizing your workshop projects, documenting your learning journey, and collaborating with team members!

## Why Notion?

- **All-in-One Workspace** - Notes, tasks, wikis, and databases in one place
- **Collaborative** - Real-time editing with team members
- **Flexible Structure** - Create custom layouts and workflows
- **Rich Content** - Embed images, videos, code, and more
- **Templates** - Pre-built structures for common use cases
- **Cross-Platform** - Works on web, desktop, and mobile
- **Free Tier** - Generous limits for personal and small team use

## Workshop Databases

### 1. Resource Database

|----------|------|-------------|
| Name | Title | Resource name |

## Common Issues & Solutions

<div class="troubleshoot-section">

### Issue: Pages load slowly
**Solution:**
1. Check internet connection
2. Reduce large images in pages
3. Try desktop app instead of web
4. Clear browser cache
5. Close unused browser tabs

### Issue: Can't share pages
**Solution:**
1. Check page permissions settings
2. Make sure you have edit access
3. Try copying the share link manually
4. Verify email addresses are correct

### Issue: Mobile app won't sync
**Solution:**
1. Check internet connection on mobile
2. Force close and reopen the app
3. Log out and log back in
4. Update to latest app version

### Issue: Databases won't load
**Solution:**
1. Refresh the page
2. Check if database has too many entries
3. Simplify database structure temporarily
4. Contact Notion support if persistent

</div>
