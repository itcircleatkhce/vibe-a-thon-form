# Figma Setup

Figma is the industry-standard collaborative design tool. It's perfect for our workshop because it runs in the browser, enables real-time collaboration, and seamlessly bridges the gap between design and development!

## Why Figma?

- **Browser-based** - Works on any device with an internet connection
- **Real-time Collaboration** - Multiple designers can work simultaneously  
- **Developer Handoff** - Easy CSS code generation and asset export
- **Component Systems** - Reusable design components and libraries
- **Prototyping** - Interactive prototypes with animations
- **Version Control** - Automatic design history and branching
- **Free for Personal Use** - Generous free tier for students and individuals

## Workshop Design Challenge

Let's create a simple mobile app mockup to test your setup:

### Challenge: Design a Workshop App Home Screen

#### Step 1: Create Mobile Frame
1. **Press F** to activate Frame tool
2. **Choose iPhone 14** from the preset sizes on the right
3. **Click to place** the frame on your canvas

#### Step 2: Add Background
1. **Select your frame**
2. **In properties panel** (right side), add a fill color
3. **Try this color:** `#F6EBD7` (Vibe-a-thon cream!)

#### Step 3: Add Header
1. **Press R** for Rectangle tool
2. **Draw header area** at the top (full width, ~80px height)
3. **Set fill color** to `#2B9A9A` (Vibe-a-thon teal)

#### Step 4: Add Title Text
1. **Press T** for Text tool
2. **Click in header** and type "Vibe-a-thon"
3. **Style the text:**
   - Font: System font or similar
   - Size: 24px
   - Color: White
   - Weight: Bold

#### Step 5: Add Content Cards
1. **Create rectangles** for content cards
2. **Apply these styles:**
   - Background: White
   - Border radius: 12px
   - Drop shadow: Y=2, Blur=8, Color=#00000020

## Collaboration Features

### Sharing Your Design
1. **Click "Share"** in the top-right
2. **Choose permissions:**
   - **View only** - Others can see but not edit
   - **Edit** - Full collaboration access
3. **Copy link** to share with team members

### Real-time Comments
1. **Press C** for Comment tool
2. **Click anywhere** to add a comment
3. **Tag team members** with @username
4. **Resolve comments** when addressed

### Version History
1. **Right-click file** in dashboard
2. **Select "Show version history"**
3. **Restore any previous version** if needed

## Common Issues & Solutions

<div class="troubleshoot-section">

### Issue: Figma web app won't load
**Solution:**
1. Check internet connection and try refreshing
2. Disable browser extensions temporarily
3. Try incognito/private mode
4. Clear browser cache and cookies
5. Try different browser (Chrome recommended)

### Issue: Can't see shared files
**Solution:**
1. Make sure you're logged into the correct account
2. Check if the file was shared with your exact email
3. Ask the owner to reshare with edit permissions
4. Try accepting the invitation email

### Issue: Desktop app won't install
**Solution:**
1. **Windows:** Run installer as Administrator
2. **macOS:** Check Security & Privacy settings
3. **Linux:** Use AppImage or Snap package instead
4. Download from official Figma website only

### Issue: Changes not saving automatically
**Solution:**
1. Check internet connection
2. Look for the "Saved" indicator in title bar
3. Try manual save with Ctrl+S
4. Refresh browser if using web version

</div>
