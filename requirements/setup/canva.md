# Canva Setup

Canva is a user-friendly graphic design platform that makes creating stunning presentations, social media graphics, and marketing materials incredibly easy. Perfect for showcasing your workshop projects and creating professional presentations!

## Why Canva?

- **Easy to Use** - No design experience required
- **Professional Templates** - Thousands of ready-made designs
- **Collaboration** - Real-time team editing and sharing
- **Brand Kit** - Consistent colors, fonts, and logos
- **Multi-format Export** - PNG, PDF, MP4, and more
- **Free Tier** - Extensive features available for free
- **Workshop Perfect** - Ideal for project presentations and demos

### Step 2: Account Setup Process

1. **Choose Sign-up Method:**
   - **Google** - Quick setup with your Gmail account (recommended)
   - **Facebook** - Use your Facebook account
   - **Email** - Create with any email address

2. **Select Purpose:**
   - Choose "Personal" for individual use
   - Select "Student" if you have a student email
   - Skip team setup for now

3. **Complete Profile:**
   - **Upload photo** (optional but recommended)
   - **Set display name** - Use your real name for team collaboration
   - **Skip paid features** - Free tier is perfect for the workshop

## Common Issues & Solutions

<div class="troubleshoot-section">

### Issue: Templates won't load
**Solution:**
1. Check internet connection
2. Clear browser cache
3. Try different browser
4. Refresh the page
5. Check if Canva is down (status.canva.com)

### Issue: Images upload slowly
**Solution:**
1. Reduce image file size (< 25MB)
2. Use supported formats (JPG, PNG, SVG)
3. Check internet upload speed
4. Try uploading one at a time

### Issue: Can't share designs
**Solution:**
1. Make sure you have edit permissions
2. Check privacy settings
3. Try copying share link manually
4. Verify email addresses are correct

### Issue: Export quality is poor
**Solution:**
1. Use higher quality export settings
2. Check original image resolution
3. Export as PDF for presentations
4. Upgrade to Canva Pro for maximum quality

</div>
